1. Programmatic API Access

Send chat messages programmatically using your generated API key:

curl -X POST http://localhost:8080/api/chat \
  -H "X-API-Key: cc_live_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"message":"How do I configure Spring Security?"}'

2. Local Offline Fallback

If GEMINI_API_KEY is not provided or when working offline, CodeCompass automatically falls back to built-in developer reasoning and diagnostic checklists without throwing blocking errors.
